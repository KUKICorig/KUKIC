## Разработка (код разбит на части)

Оригинальный файл `mindustry-studio-KUKIC-v2.9.9w.html` слишком большой для
удобной правки, поэтому проект разбит на модули в папке `src/`, а готовый
самодостаточный HTML собирается скриптом `build.py` в папку `dist/`.

Структура:

```
src/head.html      — <head> + начало <body>
src/css/main.css   — все стили
src/body.html      — вся разметка страницы
src/js-boot.js     — async-IIFE обёртка запуска (содержит маркер /*__APP_JS__*/)
src/js/*.js        — части скрипта, склеиваются по алфавиту (01-…14-), ПОРЯДОК ВАЖЕН
build.py           — сборщик
dist/              — результат (в .gitignore)
```

Команды:

```bash
python3 build.py            # собрать dist/mindustry-studio-KUKIC-v2.9.9w.html
python3 build.py --check    # только проверка синтаксиса JS (node --check)
python3 build.py --open     # собрать и открыть в браузере
```

Готовый файл из `dist/` можно открывать двойным кликом — он полностью
самодостаточен (CSS инлайнится при сборке).
