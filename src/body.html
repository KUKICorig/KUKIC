Структура модов в Mindustry (JSON)

Папки мода Mindustry:

  • mod.json — манифест в корневой папке мода.
  • content/blocks/ — постройки (турели, заводы, стены).
  • content/units/ — юниты и роботы.
  • content/items/ — новые ресурсы и руды.
  • content/liquids/ — новые жидкости и газы.
  • sprites/ — текстуры в формате PNG (имя совпадает с именем объекта).

Возможности редактора:

  • HJSON (v3.0): редактор принимает код без кавычек и запятых, а также JSON и HJSON вперемешку — key: value, "ключ": значение, ключ: "значение", элементы массива через пробел или с новой строки.
  • Комментарии // ... //: любое предложение между // и // разрешено в синтаксисе и подсвечивается синим цветом. Одиночный // до конца строки тоже работает.
  • Tab — аккуратный отступ в 2 пробела.
  • Клик по строке — полный разбор типа данных и назначения параметра.
  • Кнопка «+ Вставить» — мгновенная вставка рекомендованного поля в код.
  • Подсветка синтаксиса: ключи, строки, числа и логические значения окрашены по-разному.
  • При ошибке JSON строка с проблемой подсвечивается красным, а в статусе указывается её номер.
  • Кнопка «📂 Загрузить JSON» открывает готовый файл с диска прямо в редактор.
  • Код автоматически сохраняется в браузере (localStorage) и восстанавливается при перезагрузке.

Горячие клавиши:

  • Ctrl + S — сохранить текущий код в браузере.
  • Ctrl + Shift + F — форматировать и выровнять JSON.
